# testing_
Вводные данные:
- в поле Дано данные указываются в порядке `DailyCost, Days, IncludeInsurance`.
- позитивный тест: расчёт проходит успешно (`200`);
- негативный тест: метод отклоняет некорректные данные (`400`).

## Позитивные тесты

1 Тест - Happy Path  
Дано: 100, 5, false  
Когда: вызывается `Calculate`  
Тогда: статус `200 OK`, `TotalAmount = 500`

2 Тест - со страховкой (поиск бага)  
Дано: 100, 5, true  
Когда: вызывается `Calculate`  
Тогда: статус `200 OK`, `TotalAmount = 525` (500 * 1.05). При баге `total *= 5` получится 2500, и тест упадёт

3 Тест - нулевая стоимость дня
Дано: 0, 5, false  
Когда: вызывается `Calculate`  
Тогда: статус `200 OK`, `TotalAmount = 0`

4 Тест - копейки без страховки  
Дано: 100.50, 3, false  
Когда: вызывается `Calculate`  
Тогда: статус `200 OK`, `TotalAmount = 301.50`

5 Тест - копейки со страховкой  
Дано: 100.50, 3, true  
Когда: вызывается `Calculate`  
Тогда: статус `200 OK`, `TotalAmount = 316.575` (контроллер не округляет, `decimal` считает точно)

## Негативные тесты

6 Тест - отрицательное количество дней  
Дано: 100, -1, false  
Когда: вызывается `Calculate`  
Тогда: статус `400 Bad Request`

7 Тест - нулевое количество дней
Дано: 100, 0, false  
Когда: вызывается `Calculate`  
Тогда: статус `400 Bad Request` (условие в контроллере `Days <= 0`)
